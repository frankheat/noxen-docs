title: "Keyboard shortcuts"
description: Reference for noxen's keyboard shortcuts.
---

The footer shows the shortcuts available in the current tab.

## Everywhere

| Shortcut | Action |
| --- | --- |
| `Ctrl+Q` | Quit |
| `Ctrl+L` | Clear the current tab: History, Monitor events or Log |

## Intercept

| Shortcut | Action |
| --- | --- |
| `Ctrl+F` | Forward the held Intent; in the JSON editor, **Apply & Forward** |
| `Ctrl+D` | Drop the held Intent |
| `Esc` | Cancel the edit and keep the Intent held |
| `Ctrl+T` | Switch between detail and JSON |
| `Ctrl+B` | Show or hide the command bar |
| `Alt+Up`, `Alt+Down` | Resize the panel |

## History

| Shortcut | Action |
| --- | --- |
| `Ctrl+T` | Switch between detail and JSON |
| `Ctrl+R` | Copy the selected Intent to Sender |
| `Ctrl+B` | Show or hide the command bar |
| `Alt+Up`, `Alt+Down` | Resize the panels |

## Monitor

| Shortcut | Action |
| --- | --- |
| `Ctrl+R` | Copy the selected provider call to Sender |

## Sender

| Shortcut | Action |
| --- | --- |
| `Alt+Left`, `Alt+Right` | Move the divider between request and result |

## Info app

| Shortcut | Action |
| --- | --- |
| `Ctrl+G` | Refresh |
| `Ctrl+R` | Copy the selected component to Sender |

## JSON editor

In Sender and in the Intercept editor.

| Shortcut | Action |
| --- | --- |
| `Ctrl+Space` | List suggestions |
| `Ctrl+O` | Fold or unfold the block at the cursor |
| `Ctrl+N` | Unfold everything |
| `Esc` | Close the suggestions |

If a shortcut does nothing, your terminal or desktop may be using it first.
